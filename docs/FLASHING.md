# 刷入与恢复

> 本文写给准备把构建好的镜像刷入电视的人。新手先读 [README](../README.md) 的“三步拿到刷机包”与“常见问题”。

## 先核对

仅支持 TCL T800T11 / `tc8000_ay30a2`、Android 11、V178。电视外壳型号相同不能证明主板与分区相同。未提供其他板型兼容性保证。

每个自定义组合标为未实刷。构建成功仅证明输入、镜像结构和摘要通过检查。首次启动会安装所选组件，可能需要数分钟；本项目不自动擦除或刷写你的电视，但固件自带刷机配置可能清空应用、账号、设置。

## 文件名固定

下载成品 ZIP，解压得到完整镜像：

```
V8-T800T11-LF1V178.001228_notfull.img
```

保持这个名称，放在 U 盘根目录。不能把 ZIP 改后缀当 IMG；不能把分片之一改名当完整镜像。推荐先核对 ZIP 的 `.sha256`，再核对 ZIP 内 `SHA256SUMS`。

macOS / Linux 示例：

```sh
shasum -a 256 -c TCL-T800T11-V178-<构建编号>.zip.sha256
unzip TCL-T800T11-V178-<构建编号>.zip
shasum -a 256 -c SHA256SUMS
```

## U 盘强刷

这是维护者该板电视实际使用过的进入方式，不代表每台 TCL 电视通用：

1. 断电，插入放有完整镜像的 U 盘。
2. 按住电视**机身电源键**，再接通电源。
3. 出现刷机进度后松开，等待刷机与首次初始化完成，过程中保持供电。

本包是完整 USB `.img`，不提供已验证的 Recovery 卡刷 ZIP，也不应在 Recovery 中选择成品 ZIP。

## 原包保留与救砖

先将原救砖包另存到电脑或 NAS，保留其 SHA-256。U 盘可用其他名称保留备份；需要恢复时，把选定的原包改回上述固定名称，根目录只保留这一份待刷同名镜像，再按原有机身键流程进入强刷。

公开输入 Release `inputs-v1` 中原包以三份 `.part01` / `.part02` / `.part03` 保存，须按顺序拼接完整 IMG 后校验，不能刷任意单片：

```sh
cat V178-stock-rescue.img.part01 V178-stock-rescue.img.part02 V178-stock-rescue.img.part03 > V8-T800T11-LF1V178.001228_notfull.img
shasum -a 256 V8-T800T11-LF1V178.001228_notfull.img
```

完整原包大小 `2913239064` 字节，SHA-256：

```
d152d88de136280996b375df6e50ab5dc5210783a4a81ac156324fd6591664e7
```
